# MC Bot Suite

Автономный бот для Minecraft с графическим интерфейсом управления и полной поддержкой русского и английского языков.

## Возможности

### Основное
- Подключение к любому Minecraft-серверу (offline / online mode), версии **1.8–1.21.4**.
- Полная локализация интерфейса: **Русский** / **English**.
- 6 предустановленных цветовых тем + свободный выбор цвета фона через встроенный color picker.
- Автоматическое сохранение всех настроек в JSON.

### Функции бота
- **Навигация по маршрутам** с обходом препятствий (`mineflayer-pathfinder`).
- **Автосообщения** в чат с настраиваемым интервалом и дедупликацией.
- **Система ников**: список + случайный выбор при подключении.
- **Мониторинг** HP, голода, координат в реальном времени.
- **Safety-система**: реакция на критическое HP/голод (пауза / отключение / логирование).
- **Авто-переподключение** с настраиваемым лимитом и задержкой.
- **Авто-питание**: бот сам ест при голоде ниже порога.
- **Инвентарь**: сетка слотов, съесть / выбросить / использовать предмет.
- **Управление**: авто-удар мобов, копание по направлению, поворот на координаты.
- **Мини-карта** с треком пути и маршрутом.
- **Статистика**: uptime, distance, messages, routes, damage.

### Интерфейс
- Тёмная тема, стилизованная под десктоп-приложения.
- Скролл на всех вкладках — не обрезается на маленьких экранах.
- Горячие клавиши: `Ctrl+C` подключиться, `Ctrl+D` отключиться, `Ctrl+S` сохранить, `F5` перезапустить.
- Всплывающие уведомления (тосты) о важных событиях.
- Подтверждения для потенциально опасных действий.

## Установка

### 1. Распаковать / клонировать проект

```
mc-bot-suite/
├── app/              # Python UI
├── bot-core/         # Node.js bot
├── data/             # создаётся автоматически
├── docs/
├── run.py
├── run.bat
├── README.md
└── LICENSE
```

### 2. Установить Python-зависимости

```powershell
cd mc-bot-suite\app
python -m pip install -r requirements.txt
```

### 3. Установить Node-зависимости

```powershell
cd ..\bot-core
npm install
```

## Запуск

### Способ 1: Одной командой (рекомендуется)

```powershell
cd mc-bot-suite
python run.py
```

Скрипт поднимет `bot-core` в фоне, дождётся запуска WS-сервера, откроет UI и корректно завершит оба процесса при закрытии окна.

### Способ 2: Два окна (для отладки)

Окно 1:
```powershell
cd bot-core
npm start
```

Окно 2:
```powershell
cd app
python main.py
```

### Способ 3: `run.bat` (Windows)

Двойной клик по `run.bat` в корне проекта.

## Первый запуск

1. Открой вкладку **Настройки**.
2. Укажи:
   - **Адрес сервера** — например, `my.server.aternos.me`.
   - **Порт** — обычно `25565`, для Aternos — с панели.
   - **Версия Minecraft** — точно как на сервере.
   - **Тип авторизации** — `offline` или `microsoft`.
3. Добавь свой ник в блок **Ники** → Сохранить.
4. Перейди на **Панель** → **Подключиться**.
5. Дождись статуса **🟢 Работает**.

## Структура данных

Все файлы сохраняются в `data/` рядом с проектом:

| Файл | Содержимое |
|---|---|
| `settings.json` | Все настройки (сервер, поведение, safety, auto-eat, ui) |
| `routes.json` | Сохранённые маршруты |
| `messages.json` | Фразы для автоотправки |
| `nicks.json` | Список ников |
| `statistics.json` | Накопленная статистика |

Запись атомарная, при повреждении JSON создаётся `.bak` и применяются значения по умолчанию.

## Известные ограничения

См. [docs/LIMITATIONS.md](docs/LIMITATIONS.md). Кратко:

- **Авто-удар** работает **только на 1.20.4 и ниже**. На 1.20.5+ серверы кикают бота (`Invalid move player packet received`).
- Копание и поворот работают на всех версиях.
- Современные античиты (GrimAC) могут блокировать pathfinder.
