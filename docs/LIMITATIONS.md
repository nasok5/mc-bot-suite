# Ограничения

## Поддерживаемые версии Minecraft

- **Диапазон**: 1.8 – 1.21.4 (определяется возможностями Mineflayer).
- **Рекомендуемая**: **1.20.4** — стабильно, все функции работают.
- **1.20.5 – 1.21.4**: базовые функции (подключение, чат, инвентарь, маршруты) работают, но **авто-удар кикает**.
- **1.21.10+**: не тестировано, вероятны проблемы.

## Что работает на разных версиях

| Функция | 1.20.4 | 1.20.5–1.21.4 |
|---|:---:|:---:|
| Подключение | ✅ | ✅ |
| Чат (авто и ручной) | ✅ | ✅ |
| Инвентарь | ✅ | ✅ |
| Съесть / Выбросить | ✅ | ✅ |
| Автопитание | ✅ | ✅ |
| Маршруты (pathfinder) | ✅ | ✅ |

| **Авто-удар** | ✅ | ❌ **КИК** |

## Почему авто-удар кикает на 1.20.5+

Начиная с 1.20.5, Mojang изменила формат некоторых пакетов движения. Mineflayer не отправляет пакет `client_tick_end`, который настоящий клиент шлёт каждый физический тик. Сервер (или античит) считает бота «невалидным» и кикает с ошибкой:


Это **не баг вашего кода** — это ограничение библиотеки Mineflayer. Пользователи на GitHub воспроизводят проблему на разных серверах (Paper, Spigot, vanilla).

**Что можно сделать:**

1. **Играть на 1.20.4** — самый надёжный путь.
2. **Не использовать авто-удар** на 1.20.5+ (остальные функции работают).
3. **Ждать обновления Mineflayer** — разработчики работают над поддержкой новых версий.

## Авторизация

- **Offline mode** — `auth: 'offline'`, любой ник.
- **Online mode** — `auth: 'microsoft'`, нужен реальный аккаунт Microsoft с лицензией Minecraft.

Серверы с плагином авторизации (`/login`, `/register`) — бот **не умеет авторизовываться автоматически**, так как на каждом сервере свой плагин и разные команды авторизации. Можно вручную отправить команду через поле «Отправить сейчас» во вкладке Сообщения.

## Античиты

- **GrimAC**, **Spartan**, **Matrix** и другие современные античиты могут блокировать движения бота.
- В таких случаях pathfinder работает нестабильно: бот «залипает», получает `Kicked`.
- Обходы возможны, но требуют тонкой настройки `Movements` и эмуляции человеческого поведения. В текущей версии **не реализовано**.

## Aternos

- Работает, если сервер в **Offline Mode**.
- Порт **не 25565** — смотрите в панели Aternos.
- Адрес формата `xxx.aternos.me`.
- Первый запуск может занять 1–2 минуты (сервер стартует).

## Производительность

- **Один бот** на инстанс `bot-core`.
- **Uptime** стабилен 24/7 при хорошем соединении.
- **Память**: Node ~80–120 МБ, Python ~150–250 МБ.
- **QScrollArea** на всех вкладках — можно использовать на экранах 1280×720.

## Хранение данных

- Все JSON-файлы в `data/` пишутся атомарно.
- При повреждении JSON — `.bak` и сброс к умолчаниям.
- Резервное копирование: скопируйте папку `data/`.
