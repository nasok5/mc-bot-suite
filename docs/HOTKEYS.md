# Горячие клавиши

| Клавиша | Действие | Где работает |
|---|---|---|
| `Ctrl+C` | Подключиться к серверу | Везде |
| `Ctrl+D` | Отключиться | Везде |
| `Ctrl+S` | Сохранить настройки | Везде |
| `F5` | Перезапустить UI | Везде |
| Двойной клик по `📍 X: ... Y: ... Z: ...` | Скопировать координаты в буфер | Панель |
| Двойной клик по слоту | Использовать предмет (заглушка) | Инвентарь |
| `Enter` в поле «Отправить сейчас» | Отправить сообщение в чат | Сообщения |
